Python desde cero

Aprendé a programar con la sintaxis clara y versátil de Python, dominá estructuras de datos, incorporá programación orientada a objetos y construí scripts para automatizar tareas y dar tus primeros pasos en datos o desarrollo web.

  • Nivel: Principiante
  • Duración: 30 horas
  • Modalidad: A tu propio ritmo

¿Qué vas a aprender?

Sintaxis y Lógica Básica

Variables, operadores, condicionales (if/else), bucles (for/while) y funciones reutilizables.

Estructuras de Datos Nativas

Manejo fluido de listas, tuplas, conjuntos (sets) y diccionarios con sus métodos principales.

Programación Orientada a Objetos

Creación de clases, atributos, métodos, encapsulamiento y modularización de scripts.

Manejo de Archivos y Bibliotecas

Lectura y escritura de archivos (TXT, CSV, JSON) e instalación de paquetes externos mediante pip.

Temario del Curso

  1. Módulo 1: Introducción y Primeros Pasos

    Instalación de Python y configuración del entorno de desarrollo (VS Code / PyCharm), tipos de datos primitivos, variables y operadores.

  2. Módulo 2: Control de Flujo y Funciones

    Estructuras condicionales, bucles iterativos, definición de funciones, paso de argumentos, retornos y alcance de variables.

  3. Módulo 3: Colecciones de Datos y Manejo de Errores

    Listas y comprensiones de listas, diccionarios para modelar información estructurada, y captura de excepciones con try/except.

  4. Módulo 4: POO, Archivos y Proyecto de Automatización

    Fundamentos de clases y objetos, manipulación de archivos del sistema, uso de librerías estándar y creación de un proyecto automatizado final.

Requisitos

  • Computadora con sistema operativo Windows, macOS o Linux y conexión a internet.
  • Permisos para descargar e instalar software gratuito (Python 3 y un editor de código).
  • No se requieren conocimientos previos en programación ni en matemática avanzada.
