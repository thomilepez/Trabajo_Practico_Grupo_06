Diseño UX/UI Avanzado y Sistemas de Diseño

Llevá tus bases de diseño visual al siguiente nivel creando productos digitales interactivos, dominando research profundo, arquitectura de la información, prototipado complejo en Figma y la construcción de Design Systems escalables.

  • Nivel: Avanzado
  • Duración: 32 horas
  • Modalidad: A tu propio ritmo

¿Qué vas a aprender?

Investigación UX y Métricas

Técnicas cualitativas y cuantitativas, benchmarking competitivo, pruebas con usuarios, mapas de empatía y definición de flujos complejos.

Diseño de Sistemas y Componentes

Creación y gestión de Design Systems escalables mediante variables, tokens de diseño y Auto Layout avanzado en Figma.

Prototipado Interactivo de Alta Fidelidad

Microinteracciones fluidas, animaciones inteligentes (smart animate), estados condicionales y variables interactivas.

Accesibilidad y Handoff Profesional

Cumplimiento de pautas WCAG para interfaces inclusivas, documentación técnica y entrega fluida de especificaciones a equipos de desarrollo frontend.

Temario del Curso

  1. Módulo 1: De la Identidad Gráfica al Entorno Digital

    Traducción de marcas a interfaces vivas, responsive design para múltiples dispositivos, patrones de diseño UX comunes y arquitectura de la información avanzada.

  2. Módulo 2: Arquitectura de Componentes y Tokens

    Estructuración de componentes atómicos, variantes y booleanos, uso de variables locales (color, espaciado, radios) y mantenimiento de librerías globales.

  3. Módulo 3: Prototipado Avanzado y Microinteracciones

    Lógica condicional básica dentro de Figma, transiciones dinámicas entre pantallas, estados hover/active/disabled y diseño de interacciones realistas.

  4. Módulo 4: Usabilidad, Testing y Entrega a Desarrollo

    Planificación de sesiones de testeo con usuarios reales, iteración según métricas cualitativas, preparación de flujos para handoff y exportación de tokens para código.

Requisitos

  • Computadora con conexión a internet y navegador web moderno para utilizar Figma (versión web o desktop).
  • Haber completado el curso de Diseño Gráfico o contar con conocimientos sólidos de color, tipografía, composición visual y herramientas vectoriales.
  • No se requieren conocimientos de programación.
