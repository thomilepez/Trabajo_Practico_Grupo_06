PHP y Desarrollo Web Backend

Aprendé a construir aplicaciones web dinámicas desde el lado del servidor, gestioná peticiones HTTP, conectá bases de datos relacionales con PDO y desarrollá sistemas backend seguros y estructurados.

  • Nivel:Principiante - Intermedio
  • Duración: 28 horas
  • Modalidad: A tu propio ritmo

¿Qué vas a aprender?

Fundamentos y Sintaxis del Servidor

Variables, tipos de datos, estructuras de control, funciones y superglobales ($_GET, $_POST, $_SESSION).

Interacción con Bases de Datos

Conexión segura mediante PDO, consultas preparadas SQL para evitar inyecciones y operaciones CRUD completas.

Arquitectura y Modularidad

Separación de lógica y presentación, buenas prácticas con programación orientada a objetos (POO) y manejo de sesiones de usuario.

Seguridad y Manejo de Errores

Sanitización y validación de datos de entrada, hashing de contraseñas, control de excepciones y cabeceras HTTP.

Temario del Curso

  1. Módulo 1: Introducción a PHP y Entorno Local

    Configuración del servidor local (XAMPP / Laragon / Docker), ciclo de vida de una petición HTTP, sintaxis básica e incrustación de PHP en HTML.

  2. Módulo 2: Formularios, Sesiones y Estado

    Procesamiento de datos enviados por formularios, persistencia temporal mediante cookies y sesiones para autenticación de usuarios.

  3. Módulo 3: Base de Datos Relacional y PDO

    Modelado básico de datos, conexión robusta con PDO, consultas SELECT, INSERT, UPDATE, DELETE y sentencias preparadas seguras.

  4. Módulo 4: Proyecto Integrador Backend

    Desarrollo de un sistema funcional con login de usuarios, panel administrativo protegido y persistencia completa en base de datos.

Requisitos

  • Computadora con conexión a internet y editor de código instalado
  • Herramienta de servidor local instalada o permisos para instalarla (XAMPP, Laragon o entorno similar con soporte para PHP 8+ y MySQL).
  • Conocimientos básicos previos de HTML y nociones elementales de SQL o bases de datos.
