Desarrollo Web

PHP

Aprendé a programar el lado del servidor con PHP: sintaxis, formularios, sesiones, conexión con MySQL y programación orientada a objetos para crear sitios web dinámicos y sistemas con base de datos.

DETALLES DEL CURSO:

  • Nivel: Intermedio
  • Duración: 40 horas
  • Modalidad: A tu propio ritmo

Lleva tu carrera al próximo nivel con el curso de PHP

PARA QUIÉN ESTÁ DIRIGIDO:

Desarrolladores frontend que quieran dar el salto al backend y crear sitios web dinámicos.

Estudiantes de programación que busquen aprender a trabajar con bases de datos y formularios.

Personas que quieran iniciar su camino profesional en desarrollo web y ampliar sus oportunidades laborales.

QUÉ VAS A APRENDER:

Fundamentos de PHP

Sintaxis, variables, arreglos, estructuras de control, funciones e inclusión de archivos.

Formularios y Sesiones

Envío de datos con GET y POST, validación, cookies, sesiones y sistema de inicio de sesión.

Bases de Datos con MySQL

Conexión con PDO, consultas preparadas y operaciones CRUD de forma segura.

Programación Orientada a Objetos y Seguridad

Clases y objetos en PHP, organización del código y protección contra inyección SQL y XSS.

CONTENIDO DEL CURSO:

  1. Módulo 1: Introducción a PHP

    Instalación del entorno de desarrollo, sintaxis básica, variables, condicionales, ciclos y funciones.

  2. Módulo 2: Formularios, Cookies y Sesiones

    Recepción y validación de datos, manejo de cookies y sesiones y control de acceso de usuarios.

  3. Módulo 3: PHP y Bases de Datos MySQL

    Diseño de tablas, conexión con PDO, consultas preparadas y operaciones de alta, baja y modificación.

  4. Módulo 4: POO, Seguridad y Proyecto Final

    Clases y objetos, buenas prácticas de seguridad y desarrollo paso a paso de una aplicación web completa.

REQUISITOS:

  • Computadora con conexión a internet.
  • Editor de código (como Visual Studio Code) y un servidor local como XAMPP o Laragon.
  • Conocimientos básicos de HTML y de lógica de programación.
