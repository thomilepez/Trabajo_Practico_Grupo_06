Linux y Terminal
para Principiantes

Descubrí la potencia del sistema operativo de los servidores y el desarrollo web, dominá la línea de comandos bash, gestioná usuarios y permisos, y automatizá tareas cotidianas con scripts.

DETALLES DEL CURSO:

  • Nivel: Principiante
  • Duración: 30 horas
  • Modalidad: A tu propio ritmo

Lleva tu carrera al próximo nivel con el curso de Linux y Terminal para Principiantes

PARA QUIÉN ESTÁ DIRIGIDO:

Principiantes que quieran aprender a usar Linux y la terminal desde cero y perderle el miedo a la línea de comandos.

Programadores y estudiantes que busquen trabajar con mayor soltura en servidores y entornos de desarrollo web.

Personas que quieran iniciar su camino profesional en administración de sistemas, redes o DevOps.

QUÉ VAS A APRENDER:

Navegación y Sistema de Archivos

Estructura jerárquica de directorios, rutas absolutas y relativas, y comandos de manipulación de archivos.

Permisos y Usuarios

Sistema de seguridad de Linux, gestión de usuarios y grupos, y comandos chmod y chown.

Procesos y Monitoreo

Visualización, control y finalización de procesos en ejecución, uso de recursos y variables de entorno.

Automatización con Bash

Redirecciones, pipes, expresiones regulares básicas y creación de scripts sencillos para automatizar flujos.

CONTENIDO DEL CURSO:

  1. Módulo 1: Introducción a Linux y Navegación

    Qué es Linux, distribuciones, primeros pasos en la terminal, rutas, directorios y manipulación de archivos.

  2. Módulo 2: Usuarios, Grupos y Permisos

    Cuentas de usuario, grupos, uso de sudo, permisos de lectura, escritura y ejecución con chmod y chown.

  3. Módulo 3: Procesos, Recursos y Variables de Entorno

    Monitoreo y control de procesos, uso de CPU y memoria, y configuración de variables de entorno.

  4. Módulo 4: Bash Scripting y Proyecto Final

    Redirecciones, pipes, expresiones regulares básicas y desarrollo paso a paso de scripts para automatizar tareas.

REQUISITOS:

  • Computadora con conexión a internet.
  • Una distribución de Linux instalada, en máquina virtual (VirtualBox), WSL o arranque dual (como Ubuntu).
  • No se requieren conocimientos previos de Linux ni de programación.
