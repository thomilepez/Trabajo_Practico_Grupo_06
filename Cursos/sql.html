Bases de Datos

SQL

Aprendé a crear, consultar y administrar bases de datos relacionales con SQL: modelado, consultas, uniones, funciones de agregación y optimización para manejar la información de cualquier sistema.

DETALLES DEL CURSO:

  • Nivel: Principiante
  • Duración: 30 horas
  • Modalidad: A tu propio ritmo

Lleva tu carrera al próximo nivel con el curso de SQL

PARA QUIÉN ESTÁ DIRIGIDO:

Principiantes que quieran aprender a trabajar con bases de datos desde cero y entender cómo se almacena la información.

Desarrolladores y analistas que busquen mejorar sus consultas y obtener datos con mayor autonomía.

Personas que quieran iniciar su camino profesional en análisis de datos, backend o administración de bases de datos.

QUÉ VAS A APRENDER:

Modelado de Datos

Diseño de tablas, claves primarias y foráneas, relaciones entre entidades y normalización.

Consultas con SELECT

Filtros con WHERE, ordenamiento, límites, operadores lógicos y búsqueda de patrones con LIKE.

Uniones y Funciones de Agregación

JOIN entre tablas, GROUP BY, HAVING, funciones como COUNT, SUM y AVG, y subconsultas.

Administración y Optimización

Inserción, actualización y borrado de datos, índices, vistas, transacciones y copias de seguridad.

CONTENIDO DEL CURSO:

  1. Módulo 1: Introducción a las Bases de Datos Relacionales

    Conceptos básicos, instalación del gestor, creación de bases de datos y tablas, y tipos de datos.

  2. Módulo 2: Consultas con SELECT

    Selección y filtrado de datos, ordenamiento, operadores y manipulación de registros con INSERT, UPDATE y DELETE.

  3. Módulo 3: Relaciones, JOIN y Agrupaciones

    Claves foráneas, uniones entre tablas, funciones de agregación, agrupamientos y subconsultas.

  4. Módulo 4: Optimización y Proyecto Final

    Índices, vistas, transacciones y desarrollo paso a paso del diseño y consulta de una base de datos completa.

REQUISITOS:

  • Computadora con conexión a internet.
  • Gestor de bases de datos instalado (como MySQL Workbench, MariaDB o PostgreSQL).
  • No se requieren conocimientos previos de bases de datos ni de programación.
