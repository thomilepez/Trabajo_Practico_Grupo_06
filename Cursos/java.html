Programación
en Java

Aprendé Java desde cero: sintaxis, programación orientada a objetos, colecciones, manejo de excepciones y acceso a bases de datos para construir aplicaciones robustas y multiplataforma.

DETALLES DEL CURSO:

  • Nivel: Principiante
  • Duración: 45 horas
  • Modalidad: A tu propio ritmo

Lleva tu carrera al próximo nivel con el curso de Programación en Java

PARA QUIÉN ESTÁ DIRIGIDO:

Principiantes que quieran aprender programación desde cero con uno de los lenguajes más demandados del mercado.

Estudiantes y programadores que busquen dominar la programación orientada a objetos y mejorar su lógica.

Personas que quieran iniciar su camino profesional en desarrollo backend, aplicaciones empresariales o Android.

QUÉ VAS A APRENDER:

Fundamentos del Lenguaje

Sintaxis, variables, tipos de datos, operadores, estructuras de control y uso de la consola.

Programación Orientada a Objetos

Clases, objetos, encapsulamiento, herencia, polimorfismo, interfaces y clases abstractas.

Colecciones y Manejo de Errores

Listas, conjuntos y mapas, expresiones lambda, streams y manejo de excepciones con try-catch.

Archivos y Bases de Datos

Lectura y escritura de archivos, conexión con bases de datos mediante JDBC y operaciones CRUD.

CONTENIDO DEL CURSO:

  1. Módulo 1: Introducción a Java y Lógica de Programación

    Instalación del JDK y del entorno de desarrollo, estructura de un programa, variables, condicionales y ciclos.

  2. Módulo 2: Programación Orientada a Objetos

    Diseño de clases y objetos, constructores, herencia, polimorfismo, interfaces y buenas prácticas.

  3. Módulo 3: Colecciones, Excepciones y Archivos

    Uso de ArrayList, HashMap y otras colecciones, manejo de excepciones y persistencia en archivos.

  4. Módulo 4: Bases de Datos y Proyecto Final

    Conexión con una base de datos mediante JDBC y desarrollo paso a paso de una aplicación completa.

REQUISITOS:

  • Computadora con conexión a internet.
  • JDK instalado y un entorno de desarrollo (como IntelliJ IDEA, Eclipse, NetBeans o Visual Studio Code).
  • No se requieren conocimientos previos de programación.
