Temario del Curso

  1. Módulo 1: Fundamentos del Lenguaje Java

    Instalación del JDK y entorno de desarrollo (IDE), estructura de un programa Java, variables, condicionales y bucles.

  2. Módulo 2: Paradigma Orientado a Objetos

    Definición de clases, constructores, métodos, encapsulamiento mediante modificadores de acceso y modelado de entidades.

  3. Módulo 3: Herencia, Polimorfismo e Interfaces

    Reutilización de código, clases abstractas, sobrescritura de métodos, contratos con interfaces y modularización.

  4. Módulo 4: Colecciones, Excepciones y Proyecto Final

    ArrayList, HashMap, tratamiento de excepciones personalizadas y desarrollo de una aplicación integral por consola.
