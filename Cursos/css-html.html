Desarrollo Web

HTML5
y CSS3

Aprendé a construir páginas web desde cero: estructura con HTML5 semántico, estilos con CSS3, maquetación con Flexbox y Grid y diseño responsive para que tus sitios se vean bien en cualquier dispositivo.

DETALLES DEL CURSO:

  • Nivel: Principiante
  • Duración: 40 horas
  • Modalidad: A tu propio ritmo

Lleva tu carrera al próximo nivel con el curso de HTML5 y CSS3

PARA QUIÉN ESTÁ DIRIGIDO:

Principiantes que quieran aprender a crear páginas web desde cero sin necesidad de experiencia previa.

Diseñadores y creadores de contenido que busquen dar vida a sus diseños con código propio.

Aspirantes a desarrolladores que quieran iniciar su camino profesional en el desarrollo web frontend.

QUÉ VAS A APRENDER:

HTML5 Semántico

Etiquetas semánticas, enlaces, imágenes, listas, tablas, formularios y buenas prácticas de accesibilidad.

Estilos con CSS3

Selectores, modelo de caja, tipografía, colores, variables CSS, sombras, degradados y transiciones.

Maquetación con Flexbox y Grid

Distribución de elementos en filas, columnas y cuadrículas para crear layouts flexibles y ordenados.

Diseño Responsive

Media queries, enfoque mobile first, unidades relativas e imágenes adaptables a cualquier pantalla.

CONTENIDO DEL CURSO:

  1. Módulo 1: Fundamentos de HTML5

    Estructura de un documento, etiquetas semánticas, texto, enlaces, imágenes, listas, tablas y multimedia.

  2. Módulo 2: Formularios y Accesibilidad

    Campos y tipos de entrada, validación nativa, atributos ARIA y buenas prácticas de SEO básico.

  3. Módulo 3: Fundamentos de CSS3

    Cómo vincular CSS al HTML, selectores, cascada, especificidad, modelo de caja, texto, color y fondos.

  4. Módulo 4: Layouts, Responsive y Proyecto Final

    Flexbox, Grid, media queries, transiciones y desarrollo paso a paso de un sitio web completo y adaptable.

REQUISITOS:

  • Computadora con conexión a internet.
  • Editor de código (como Visual Studio Code) y un navegador web actualizado.
  • No se requieren conocimientos previos de programación ni de diseño.
