JavaScript Moderno y Desarrollo Web Dinámico

Dominá el lenguaje esencial de la web desde las bases hasta ECMAScript moderno, aprendé a manipular el DOM, gestioná asincronía con promesas y APIs, y creá interfaces interactivas para proyectos reales.

  • Nivel: Principiante - Intermedio
  • Duración:28 horas
  • Modalidad: A tu propio ritmo

¿Qué vas a aprender?

Sintaxis y Lógica Central

Variables, tipos de datos, operadores, funciones y control de flujo en JavaScript.

Manipulación del DOM y Eventos

Selección de nodos, modificación dinámica de estilos y contenido, y captura de eventos del usuario.

JavaScript Asíncrono

Uso de fetch, Promesas, async/await y consumo de datos mediante APIs REST en formato JSON.

Buenas Prácticas y Modularidad

Módulos ES6, alcance léxico (scope), closures y organización de código limpio y reutilizable.

Temario del Curso

  1. Módulo 1: Fundamentos y Sintaxis Moderna

    Entorno de ejecución, vinculación con HTML, variables, tipos primitivos, condicionales, bucles y funciones flecha.

  2. Módulo 2: Interacción con el Navegador y DOM

    Selección y recorrido de elementos, creación dinámica de etiquetas, clases CSS dinámicas y listeners de eventos.

  3. Módulo 3: Asincronía y Conexión con APIs

    Manejo del tiempo de respuesta, promesas, llamadas HTTP con Fetch API, renderizado de datos remotos y control de errores.

  4. Módulo 4: Proyecto Práctico Integrador

    Estructuración de una aplicación web interactiva con persistencia de datos local (LocalStorage) y consumo de servicios web.

Requisitos

  • Computadora con conexión a internet y navegador web moderno instalado.
  • Editor de código sugerido (como Visual Studio Code).
  • Conocimientos básicos previos de estructura HTML y estilos CSS.
