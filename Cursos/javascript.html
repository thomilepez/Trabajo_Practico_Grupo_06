Desarrollo Web

JavaScript

Aprendé el lenguaje de la web: variables, funciones, manipulación del DOM, eventos y asincronía para crear páginas interactivas y dinámicas que responden a las acciones del usuario.

DETALLES DEL CURSO:

  • Nivel: Principiante
  • Duración: 35 horas
  • Modalidad: A tu propio ritmo

Lleva tu carrera al próximo nivel con el curso de JavaScript

PARA QUIÉN ESTÁ DIRIGIDO:

Principiantes que quieran aprender programación desde cero con un lenguaje accesible y versátil.

Personas que dominan HTML y CSS y quieran darle interactividad a sus sitios web.

Aspirantes a desarrolladores que quieran iniciar su camino profesional en desarrollo frontend o fullstack.

QUÉ VAS A APRENDER:

Fundamentos del Lenguaje

Variables, tipos de datos, operadores, condicionales, ciclos y funciones con la sintaxis moderna (ES6+).

Arreglos y Objetos

Manejo de arreglos y objetos, métodos como map, filter y reduce, desestructuración y formato JSON.

DOM y Eventos

Selección y modificación de elementos, creación de contenido dinámico, formularios y manejo de eventos.

Asincronía y APIs

Promesas, async/await, fetch para consumir APIs y almacenamiento de datos con localStorage.

CONTENIDO DEL CURSO:

  1. Módulo 1: Fundamentos de JavaScript

    Cómo vincular JavaScript al HTML, variables, tipos de datos, operadores, condicionales y ciclos.

  2. Módulo 2: Funciones, Arreglos y Objetos

    Funciones flecha, ámbito, arreglos, objetos, métodos de orden superior y trabajo con JSON.

  3. Módulo 3: Manipulación del DOM y Eventos

    Selección de elementos, modificación de estilos y contenido, validación de formularios y eventos del usuario.

  4. Módulo 4: Asincronía, APIs y Proyecto Final

    Promesas, async/await, consumo de APIs con fetch y desarrollo paso a paso de una aplicación web interactiva.

REQUISITOS:

  • Computadora con conexión a internet.
  • Editor de código (como Visual Studio Code) y un navegador web actualizado.
  • Conocimientos básicos de HTML y CSS. No se requiere experiencia previa en programación.
