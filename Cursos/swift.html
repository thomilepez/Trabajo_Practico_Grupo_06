¿Qué vas a aprender?

Sintaxis y Seguridad en Swift

Tipado estático, constantes, variables, tipos opcionales (optionals) y desempaquetado seguro con guard e if let.

Programación Orientada a Protocolos

Clases, estructuras (structs), enumeraciones avanzadas, propiedades calculadas y extensiones.

Interfaces con SwiftUI

Diseño declarativo de vistas, manejo de estados con @State y @Binding, y navegación fluida entre pantallas.

Persistencia y Conexión a Red

Decodificación de datos JSON con el protocolo Codable, peticiones HTTP con URLSession y almacenamiento local básico.

Temario del Curso

  1. Módulo 1: Fundamentos del Lenguaje Swift

    Entorno Xcode y Swift Playgrounds, tipos de datos básicos, operadores, control de flujo, funciones y colecciones (Arrays, Dictionaries).

  2. Módulo 2: Modelado de Datos y Paradigmas

    Diferencias entre struct y class, constructores, manejo seguro de opcionales, closures y principios de programación orientada a protocolos.

  3. Módulo 3:Introducción a SwiftUI

    Jerarquía de vistas, contenedores de diseño (VStack, HStack, ZStack), modificadores de vista, componentes de formulario y gestión del estado reactivo.

  4. Módulo 4: Proyecto Integrador iOS

    Construcción de una app completa que consume una API pública, maneja errores de red, muestra listados dinámicos y persiste preferencias del usuario.
